# 퍼플루 (Purplu)

말로 시키면 PC에서 앱을 열고, 앱 안에서 직접 조작하고(계산기 등), 파일·웹을 찾아주는 보라색 AI 컴패니언.
PC와 갤럭시 탭에서 같이 쓸 수 있어요. 전체 계획은 [PLAN.md](PLAN.md).

## 실행 (PC)

`run.bat` 더블클릭 (처음엔 필요한 것들을 설치합니다). 이미 켜져 있으면 끄고 새로 켜고, `requirements.txt`가 바뀌면 알아서 설치해요.
GitHub의 최신 버전으로 바꾸려면 `update.bat` 더블클릭 (내 `data` 폴더는 그대로 남아요).
작업 표시줄 트레이에 퍼플루 아이콘이 생겨요.

- **F9를 누르고 있는 동안 말하고, 떼면** 대답해요 (말풍선은 화면 오른쪽 아래)
- **퍼플루 커서**(물방울 모양 + 말랑한 눈)는 원본처럼 **필요할 때만** 나타나요: 가리키기·클릭·하이라이트할 때
  오른쪽 아래에서 혜성 꼬리를 남기며 날아갔다가, 끝나면 스르르 사라져요.
- 설정에서 "커서 항상 보이기"를 켜면 오른쪽 아래에 머물고, 그때는 커서를 **꾹 누르기 = 말하기, 우클릭 = 설정**
- 말풍선 우클릭 또는 트레이 메뉴 → 설정창 (대화목록 · 메모 · 목소리 · 설정 · 갤럭시 탭)
- 처음엔 설정 → **키 입력/변경**에서 Gemini 키를 넣어요. 키는 이 PC의 Windows 자격 증명 관리자에만 저장돼요.

| 단축키 | 하는 일 |
| --- | --- |
| F9 (누르고 있기) | 말하기 |
| Ctrl+Alt+P | 퍼플루 커서가 지금 마우스 자리로 날아가 가리키기 |
| Ctrl+Alt+H | 커서 항상 보이기 켜기/끄기 |
| Ctrl+Alt+D | 커서 집으로 |
| Ctrl+Alt+S | 비상정지 (조작 즉시 멈춤) |

## 이런 걸 시켜요

- (마우스를 올려 두고) "이게 뭐야?" → 마우스 아래 있는 걸 가리키며 설명 (원본 기능)
- "크롬 열어줘", "카톡 켜줘", "유튜브 열어줘"
- "계산기에서 3 곱하기 9 해줘" → 계산기를 열고 퍼플루 커서가 직접 입력, 결과(27)를 읽어 줌
- "지금 화면에서 저장 버튼 어디 있어?" → 커서가 날아가서 가리키고 **하이라이트**(반짝이는 테두리 + 이름표)
- "계산기에서 곱하기랑 결과 칸 표시해줘" → 여러 군데를 한 번에 하이라이트
  (화면 글자는 Windows 글자 인식(OCR)으로 정확한 위치를 찾고, 못 찾으면 Gemini가 스크린샷에서 찾아요)
- "이거 메모해줘", "내일 3시 회의 기억해 둬" → 화면 오른쪽 위에 **포스트잇 메모** (탭에서도 보여요)
- "10분 뒤에 알려줘", "3시에 회의 알려줘" → 때가 되면 퍼플루가 **목소리로 알려 주고** 말풍선·탭에 ⏰ (탭은 진동)
- "볼륨 30으로", "소리 줄여줘", "음소거", "음악 멈춰", "다음 곡" → PC 소리·음악 조절
- "복사한 거 요약해줘", "이거 영어로 번역해서 복사해줘" → 복사(Ctrl+C)한 글을 읽고, 결과를 다시 클립보드에
- "지난주에 받은 PDF 찾아줘" → "첫 번째 거 열어줘"
- "내일 서울 날씨 알아봐줘" → 웹 검색 리포트

## 대화목록

설정창 💬 대화 탭에서 **새 대화**, 대화 목록 보기, **이 대화로 이어가기**(골라서 이어서 말하기), 이름 바꾸기, 삭제.
나눈 말은 대화마다 저장되고, 이어가기를 고르면 그 대화 내용을 기억한 채로 다시 시작해요.

## 생각·실행 명령 보기 (Claude처럼)

말풍선에 퍼플루가 **실행하는 명령**이 `open_app(name="계산기")` → `└ 열었어: 계산기 · 1.6초`처럼 나와요.
**생각하는 모델**(설정 → 대화 모델: gemini-3.8-live-extended-thinking)을 쓰면 💭 생각 내용도 나와요. 대신 대답이 조금 느려져요.
그 아래에 **실제로 실행하는 명령어**도 `$ explorer.exe "shell:AppsFolder\Microsoft.WindowsCalculator…"`,
`$ SendInput(KEYEVENTF_UNICODE, '3*9=')`, `$ Windows Search(ADODB): SELECT …`, `$ HTTP POST https://…firebase…/purplu/memos` 처럼 나와요.
설정 → ⚙ 설정의 "생각 내용 보여주기", "실행하는 명령과 결과 보여주기", "실제로 실행하는 명령어도 보여주기"로
각각 켜고 끌 수 있어요 (탭 설정에도 있어요).

## 속도

- 기본 모델은 빠른 **gemini-3.8-live**. 켜자마자 Gemini에 미리 연결해 두고, 끊기면 뒤에서 다시 연결해요.
  → 말을 마치고 약 1초 안에 대답이 시작돼요.
- 화면 보기는 버튼 정보가 충분하면 글자 인식(OCR)을 기다리지 않고, 같은 화면은 방금 읽은 걸 다시 써요.

## 목소리 고르기

설정창 🔊 목소리 탭(PC·탭)에서 30가지 목소리를 **▶ 들어보고**, 마음에 들면 **✓ 이 목소리로 정하기**.
처음 듣는 목소리는 Gemini로 만드는 데 몇 초 걸리고, 한 번 들은 건 `D:\bot\data\voices`에 저장돼서 바로 나와요.

## 회의록 (원본의 Meeting notes)

"회의록 시작해" 또는 트레이 메뉴 **● 회의록 시작** → PC 마이크로 계속 녹음해요 (말풍선·트레이에 ● REC 시간).
5분마다 Gemini가 **화자를 구분해서** `[mm:ss] 화자 1: …` 형식으로 받아써 `notes.md`에 쌓아요.
"회의록 끝내" 또는 **■ 회의록 끝내기** → 마지막 부분까지 받아쓰고 맨 위에 **요약 · 결정된 것 · 할 일**을 정리해요.

저장 위치: `D:\bot\data\notes\<날짜 시간 제목>\` (`notes.md`, `audio\chunk_001.wav` …), 트레이 → **회의록 폴더 열기**.
설정의 `notes_dir`로 바꿀 수 있어요. 녹음은 PC 마이크로만 돼요 (탭 마이크는 아직).

## 메모

퍼플루가 남긴 메모는 PC 화면 오른쪽 위에 포스트잇으로 붙어요. 끌어서 옮길 수 있고, 📌 = 화면에서 떼기(메모는 남음), 🗑 = 지우기.
설정창 📝 메모 탭(PC·탭)에서 직접 쓰고, 붙이고, 지울 수 있어요. 메모도 Firebase로 실시간 동기화돼요.

## 퍼플루 색

설정 → ⚙ 설정 → **퍼플루 색**에서 견본을 누르거나 "직접…"으로 아무 색이나 고를 수 있어요 (탭 설정에서도 가능).
커서, 말풍선, 트레이 아이콘, 하이라이트, 탭 얼굴이 모두 그 색으로 바뀌어요. 상태(듣는 중·생각 중·하는 중)는 테두리 색으로 보여요.

## 이 PC 브라우저에서 시험하기

`http://localhost:8765` — PC 안에서는 http로도 마이크가 돼요.

## 갤럭시 탭에서 쓰기

1. 탭과 PC를 **같은 와이파이**에 연결 (게스트 와이파이는 안 됨)
2. PC에서 퍼플루 우클릭 → 설정 → **📱 갤럭시 탭** 탭: 주소(`https://PC주소:8766`)와 QR이 나와요
   (탭에서 `http://PC주소:8765`로 들어가도 자동으로 https 주소로 옮겨 줘요)
3. 탭 카메라로 QR을 찍거나, 탭 크롬에 그 주소를 입력
4. "연결이 비공개로 설정되어 있지 않습니다" → **고급 → 계속 진행** (PC가 직접 만든 인증서라서 나오는 경고예요. 마이크를 쓰려면 https가 꼭 필요해요)
5. 퍼플루를 톡 누르고 **마이크 허용**
6. 크롬 메뉴 ⋮ → **홈 화면에 추가** 하면 앱처럼 전체화면으로 써요

탭 화면은 원본처럼 **검은 화면 아래에서 큰 퍼플루 얼굴이 쏙 올라온 모습**이에요.
- **두 번 톡 = 깨우기/재우기**, **꾹 누르고 있는 동안 말하기, 떼면 대답**, 오른쪽 위 흐린 **⚙ = 설정창**
- 눈은 PC 마우스를 따라 쳐다보고(탭을 모니터 아래 두면 딱), 손가락을 대면 손가락을 봐요
- 표정: 듣는 중(눈 크게), 생각 중(위를 보며 점점점), 가리키는 중(집중), 말하는 중(입 뻥긋), 대답 끝(^^ 방긋), 자는 중(z)
- 가끔 깜빡이고(두 번 깜빡이기도), 심심하면 콩 뛰어요. 화면 가장자리 빛 색깔로 상태를 알려 줘요
- 대답할 때 **짹** 소리. 탭 설정에서 크기 조절, "대답 글자도 보이기"를 켜면 글자도 나와요 (기본은 얼굴만)
탭은 마이크·스피커·얼굴 역할만 하고 생각과 조작은 PC가 해요. 그래서 Gemini 키는 탭에 가지 않아요.

안 될 때 (PC에서는 되는데 탭에서 안 열릴 때):
- **와이파이가 "공용 네트워크"로 되어 있으면 Windows 방화벽이 막아요.** 설정창 📱 탭에 빨간 경고가 나와요.
  Windows 설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 와이파이 이름 → **네트워크 프로필 유형: 개인 네트워크**
- PC에서 처음 켤 때 **Windows 방화벽** 창이 뜨면 "개인 네트워크" 허용
- 탭에 "PC 연결 끊김"이 계속 보이면 PC의 퍼플루가 켜져 있는지, 같은 와이파이인지 확인

## 설정 저장 위치

설정과 대화목록은 Firebase Realtime Database에 저장돼요 (로그인 없음). 주소는 `D:\bot\data\firebase_url.txt`에만 있어요
(코드·GitHub에 올라가지 않게). 새 PC에 설치할 땐 이 파일에 자기 Firebase RTDB 주소를 한 줄로 넣으면 돼요.
PC와 탭이 같은 설정을 쓰고, **실시간으로 동기화**돼요. 탭이나 다른 PC에서 색·설정을 바꾸거나 대화를 고르면 1초 안에 반영돼요.
인터넷이 안 될 땐 `D:\bot\data\settings.json` 사본을 쓰고, 다시 연결되면 자동으로 따라잡아요.

문제가 생기면 `D:\bot\data\purplu.log` 에 오류가 남아요. 퍼플루는 한 번에 하나만 켜져요.

> ⚠ 로그인이 없으니 이 주소를 아는 사람은 누구나 설정과 대화 내용을 읽고 쓸 수 있어요.
> 그래서 Gemini 키는 Firebase에 절대 올리지 않아요. 대화에 비밀 이야기는 하지 마세요.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `live_model` | `gemini-3.8-live-extended-thinking` | 빠른 대답이 좋으면 `gemini-3.8-live` |
| `thinking_level` | `low` | `low` / `medium` / `high` |
| `show_thoughts` | `true` | 생각 요약 보여주기 (모델이 보내줄 때) |
| `voice` | `Leda` | 목소리 |
| `talk_key` | `f9` | 누르고 말하는 키 (바꾸면 재시작) |
| `speak` | `true` | 목소리로 대답 |
| `computer_control` | `true` | 클릭·타이핑으로 PC 조작 허용 |
| `cursor_visible` / `cursor_follow` / `cursor_size` | 켬 / 끔 / 64 | 퍼플루 커서 |
| `color` | `#8B5CF6` | 퍼플루 색 |
| `tablet_port` | `8765` | http 포트 (https는 +1 = 8766) |

## 웹으로 열기 (GitHub Pages)

`https://내아이디.github.io/PPB/` 링크를 열면 그게 바로 퍼플루 화면이에요 (localhost 대신).
1. PC 퍼플루 설정 → ⚙ 설정 → **🌐 웹 주소**에 Pages 주소를 넣어요.
2. 설정 → 갤럭시 탭의 QR이 `…github.io/PPB/?pc=PC주소:8766` 링크로 바뀌어요. 찍으면 바로 연결되고, 주소는 기억돼요.
3. 처음 한 번: 화면에 나오는 **퍼플루 인증서 받기**(설치하면 경고가 영영 안 떠요) 또는 **PC 연결 허용하기**.

🔒 PC와 **같은 와이파이**에서만 연결돼요. 다른 와이파이·인터넷에서 오는 접속, 그리고 내 Pages가 아닌 다른 웹사이트의 연결은 PC가 막아요.
화면을 고친 뒤엔 `.venv\Scripts\python build_pages.py` → 커밋·푸시하면 Pages에 반영돼요. 소개 페이지는 `docs/about.html`.

## 크롬 확장 (퍼플루 브라우저 손)

퍼플루가 크롬을 정확하게 다루게 해 주는 확장이에요. 화면을 눈대중으로 보는 대신 페이지 글·버튼·입력칸을 직접 읽고 눌러요.
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → `D:\bot\chrome_extension` 폴더 선택
3. 퍼플루가 켜져 있으면 자동 연결돼요 (확장 아이콘을 누르면 "● 퍼플루와 연결됨")

이 PC 안의 크롬 확장만 연결할 수 있어요. 비밀번호 칸은 보안 수준이 '강하게'면 입력하지 않아요.

**2.0 (Claude in Chrome처럼)**
- 클릭·입력을 **진짜 마우스·키보드 신호**(크롬 디버거)로 보내서 웹페이지가 무시하지 않아요. 크롬 위에 "디버깅 중" 알림이 떠요.
- 키보드: Enter, Tab, Esc, 화살표, Ctrl+A 등 (`browser_keys`). 한글 입력도 그대로 들어가요.
- 크롬 화면 사진(`browser_screenshot`)을 보고 번호가 없는 아이콘 버튼도 좌표로 눌러요.
- **🖍 하이라이트·📝 노트**: 글을 드래그하면 형광펜(4색)과 노트 버튼이 떠요. 칠한 곳을 누르면 노트를 쓰거나 지워요.
  사이트(주소)마다 저장돼서 **스크롤·새로고침·다음 방문에도 그대로** 남아요. 퍼플루에게 "이 문장 칠해 두고 노트 남겨"라고 해도 돼요.
- **💜 작업 중 표시**: 퍼플루가 쓰는 탭은 가장자리가 빛나고 은은하게 빛나요 (글자 없이 색만).
  계산기 같은 PC 앱을 조작할 땐 그 창 둘레에 같은 빛 테두리가 생겨요. 설정에서 켜고 끄고, 색도 바꿔요(비우면 퍼플루 색).
- **크롬·웨일·엣지** 모두 같은 확장을 쓸 수 있어요 (웨일은 `whale://extensions`에서 같은 폴더를 로드).
  여러 개 켜 두면 마지막으로 쓴 브라우저로 명령이 가요. 기본 브라우저가 달라도 링크는 확장이 있는 브라우저에서 열려요.
- 켜고 끄기: 퍼플루 설정의 "🌐 크롬: 진짜 마우스·키보드", "🖍 크롬: 사이트 하이라이트·노트" (또는 확장 아이콘 팝업)
- 업데이트 후엔 `chrome://extensions`에서 퍼플루 확장의 ↻ 새로고침 (새 권한 때문에 다시 켜기를 물어볼 수 있어요)

## 패드 화면 나누기

생각하거나 결과를 알려 줄 때 패드 화면이 반으로 나뉘어 왼쪽엔 퍼플루, 오른쪽엔 생각·실행 명령·대답·결과가 나와요.
오른쪽 위 **◧** 로 열고 닫고, **✕** 로 닫으면 그 대답 동안은 다시 안 열려요.
패드 설정에서 "결과가 나오면 화면 나누기", "생각할 때도 화면 나누기"를 각각 끌 수 있어요.

## 대화방 (제미나이처럼)

탭·웹 링크로 열면 오른쪽에 **대화방**이 떠요. 지금 대화의 지난 말들이 이어서 나오고, 아래 **빛이 도는 입력칸**에 글로 쓰면 돼요.
- 🎤 버튼이나 퍼플루 얼굴을 **꾹 누르고 있는 동안 말하기** (그대로예요)
- 대화창 모양 (머리줄 버튼으로 차례로 바꾸기): **◳ 오른쪽 아래 창**(기본, 퍼플루 얼굴 위에 떠 있어요) · **◧ 반반** · **⤢ 대화창만**
- **⚙** = 설정, **✕** = 닫기 (오른쪽 아래 💬 동그라미로 다시 열기)
- 설정 → 화면: 대화창 모양, **입력칸 빛 색**(다채로운 기본 · 파랑-보라 · 분홍-보라 · 노을 · 바다 · 퍼플루 색 하나), **대화창 색**(내 말풍선·보내기 버튼)
- 색 배경 위 글자는 자동으로 흰색/진한색이 돼요 (빨간 말풍선엔 흰 글자)
- **PC에서도**: 트레이 → **💬 대화창 열기** 또는 **Ctrl+Alt+C** — 브라우저 없이 같은 대화창이 열려요
  - 설정 "💬 말풍선 대신 대화창"(기본 켜짐): PC에서 말하면 말풍선 대신 오른쪽 아래에 이 대화창이 떠서 글로도 이어서 쓸 수 있어요. 끄면 예전 말풍선.

## 글로 채팅 · 그림 · 모델

- 탭/웹 화면 왼쪽 위 **💬** 또는 PC 트레이 → **글로 채팅하기**: 오른쪽 화면 아래 칸에 글로 말해요 (Enter 보내기).
  말로 한 대화와 **같은 대화**라서 글로 한 걸 말로 이어서 물어봐도 기억해요 (대화목록에도 같이 저장).
- **📎** 그림 첨부 (Ctrl+V 붙여넣기도 돼요) → "이거 뭐야?", "이 그림 고쳐 줘"
- 채팅 칸 옆에서 **⚡ 빠른 / 🧠 생각하는 모델**을 바로 바꿔요.
- "고양이 그림 그려 줘" → 그림을 만들어 오른쪽 화면에 보여 주고 `data\images`에 저장해요.
  (그림 모델은 Gemini 키에 결제가 켜져 있어야 쓸 수 있어요. 무료 키는 한도가 0이라 안 될 수 있어요.)

## 스킬

스킬 = 퍼플루가 따라 할 **할 일 설명서**예요. 이름·언제 쓰는지·단계별 설명을 적어 두면, 그 말이 나올 때 퍼플루가 설명서대로 해요.
- 탭 설정 → **🧩 스킬**에서 만들고, 고치고, 켜고 끄고, 지워요. 말로 "이걸 스킬로 저장해"라고 해도 돼요.
- 예시 스킬 3개가 들어 있어요: 아침 브리핑, 번역해서 복사, 집중 모드

## 보안 수준 · 화면 테마

설정 → ⚙ 설정(탭 설정에도 있어요)의 **🔒 보안 수준**:
| 수준 | 하는 일 |
| --- | --- |
| 강하게 (기본) | 비밀번호·개인정보 막기, 로그인·글 올리기·메일·삭제 등은 매번 물어보기, 파이썬은 매번 확인 |
| 보통 | 시킨 일은 바로, 돈이 드는 일만 물어보기, 내가 말해 준 비밀번호는 입력 가능, 파이썬은 안전하면 자동 |
| 약하게 | 개인정보·비밀번호 허용, 거의 묻지 않고 바로, 파이썬 모두 자동 (결제·송금만 한 번 확인) |

낮출 때는 무엇이 위험해지는지 **경고창**이 뜨고 동의해야 바뀌어요. 비밀번호 칸 입력은 크롬 확장 1.1.0부터 돼요
(`chrome://extensions`에서 퍼플루 확장의 ↻ 새로고침). 입력한 글은 화면 기록에 `<N자 가림>`으로만 보여요.

**🎨 화면 테마**: 어둡게 / ☀ 밝게(흰 배경) — 설정창·말풍선·실행 확인창·탭 화면에 모두 적용돼요.

## 데이터 위치

퍼플루의 데이터는 전부 **`D:\bot\data\`** 에 있어요 (C 드라이브는 쓰지 않아요).

| 폴더·파일 | 내용 |
| --- | --- |
| `data\settings.json` | 설정 사본 (진짜 설정은 Firebase) |
| `data\purplu.log` | 오류 기록 |
| `data\voices\` | 미리 들어 본 목소리 |
| `data\notes\` | 회의록 |
| `data\python\` | 퍼플루가 실행한 파이썬 코드(`run_001.py` …)와 만든 파일 |
| `data\tablet-*.pem` | 탭 연결용 인증서 |

예전 버전이 `%APPDATA%\Purplu`에 저장한 데이터는 다음에 켤 때 자동으로 `data\`로 옮겨져요.
Gemini 키만은 파일이 아니라 Windows 자격 증명 관리자에 그대로 있어요(보안상 파일로 두지 않아요).

## 파이썬 실행

다른 도구로 안 되는 일(복잡한 계산, 표·CSV 정리, 파일 만들기·변환, 데이터 분석)은 퍼플루가 파이썬 코드를 써서 실행해요.
코드는 따로 떨어진 파이썬에서, `data\python\` 안에서, 시간 제한(기본 60초)을 두고 돌아요.

설정 → **🐍 실행 전 확인**:
- **매번 물어보기** (기본): 실행 전에 코드를 보여 주는 확인창이 PC와 탭에 같이 떠요
- **안전해 보이면 자동 실행**: 코드를 미리 검사해서 파일 지우기·다른 프로그램 실행·인터넷 접속·시스템 접근·작업 폴더 밖 경로가
  없으면 바로 실행하고, 있으면 위험한 부분을 빨갛게 표시해서 물어봐요
- **모두 자동 실행**: 검사와 상관없이 바로 실행 (경고가 기록에 남아요)

자동 실행으로 바꿀 땐 경고창이 떠서 동의해야 바뀌어요. 검사는 완벽하지 않으니 자동 실행은 조심해서 쓰세요.

## 구조

- `purplu/brain.py` Gemini Live 세션 (누르고 말하기, 생각, 도구 호출, 대답, 대화 저장)
- `purplu/cursor.py` 화면 위 퍼플루 커서 (날아가기, 가리키기, 생각 거품, 우클릭/길게 → 설정)
- `purplu/highlight.py` 화면 하이라이트 (반짝이는 테두리 + 이름표, 클릭은 통과)
- `purplu/memo.py` 화면 포스트잇 메모
- `purplu/trace.py` 실행 명령어 기록, `purplu/tools/pyrun.py` 파이썬 실행·위험 검사
- `purplu/settings_window.py` 설정창 (대화목록 · 설정 · 탭 연결)
- `purplu/server.py` + `purplu/web/tablet.html` 갤럭시 탭 연결 (https + WebSocket)
- `purplu/store.py` Firebase 저장 + 실시간 동기화, `purplu/config.py` 설정·키
- `purplu/tools/` 도구: `apps.py` 앱·사이트, `files.py` 파일 찾기, `web.py` 웹 조사, `control.py` 화면 보기·클릭·타이핑·하이라이트, `ocr.py` 화면 글자 인식, `locate.py` 위치 찾기(OCR → Gemini), `memos.py` 메모
