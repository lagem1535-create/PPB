할 수 있는 일

🗣 말로·글로 대화

F9를 누르고 말하거나 글로 채팅. 둘 다 같은 대화로 이어져요.

🖱 PC 직접 조작

앱 열기, 클릭·입력, 계산기 계산, 화면 속 버튼 찾아 하이라이트.

🌐 크롬 손

크롬 확장으로 페이지를 정확하게 읽고, 누르고, 입력해요.

📱 갤럭시 탭 얼굴

탭이 큰 얼굴이 되고, 결과·생각은 화면을 나눠 보여 줘요.

🧩 스킬

할 일 설명서를 만들어 두면 그 말이 나올 때 그대로 해요.

🐍 파이썬

복잡한 계산·파일 변환은 코드를 써서 실행 (실행 전 확인).

💻 Windows 기본

배터리·PC 상태, 밝기, 다크 모드, 잠금·절전·끄기, 창 다루기.

📝 메모·⏰ 알림·🎙 회의록

포스트잇 메모, 목소리 알림, 화자 구분 회의록과 요약.

설치 방법

  1. Windows 10/11 PC에 Python 3.12 이상과 Git을 설치해요.
  2. 받기: 
    git clone https://github.com/lagem1535-create/PPB.git
cd PPB
  3. Firebase에서 Realtime Database를 만들고, 그 주소를 data\firebase_url.txt에 한 줄로 넣어요. (설정·대화목록이 여기에 저장돼요)
  4. run.bat을 더블클릭 → 트레이 아이콘 → 설정에서 Gemini 키를 넣어요. 키는 Windows 자격 증명 관리자에만 저장돼요.
  5. 갤럭시 탭: 같은 와이파이에서 설정 → 갤럭시 탭의 QR을 찍고, 안내대로 퍼플루 인증서를 한 번 설치하면 경고 없이 열려요.
  6. 크롬 확장: chrome://extensions → 개발자 모드 → 압축해제된 확장 로드 → chrome_extension 폴더.

🔒 퍼플루 화면은 PC와 같은 와이파이에서만 열려요. 인터넷·다른 와이파이에서는 막혀요. 이 페이지(GitHub Pages)는 소개와 설치 안내만 있고, 퍼플루 자체는 내 PC에서 돌아가요.
